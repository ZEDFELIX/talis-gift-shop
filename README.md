# ZED Gift Shop — Vercel Compatibility Copy

This repository is the older Talis Gift Shop codebase that has since been rebranded toward ZED Gift Shop.

**Canonical current Gift Shop repository:** [ZEDFELIX/zed-gift-shop](https://github.com/ZEDFELIX/zed-gift-shop)

The Vercel project currently connected to this repository is retained for compatibility/history. Do not split new product, checkout, design or backend work between the two codebases.

## Legacy stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS
- Prisma
- SQLite-oriented local development
- M-PESA Daraja integration

## Important

For new Gift Shop features and fixes, work in `ZEDFELIX/zed-gift-shop`. This repository should only receive changes when specifically required to keep the existing Vercel compatibility deployment working.
